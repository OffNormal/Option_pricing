## Введение

OptionPricer - это профессиональная платформа оценки опционов, предоставляющая финансовым специалистам, количественным аналитикам и исследователям точные и быстрые расчеты цен опционов. Система использует C++17 для реализации основного вычислительного движка, обеспечивая высокую производительность и численную стабильность, а также предоставляет интуитивный пользовательский опыт через современный веб-интерфейс.

### Основные преимущества

- 🚀 **Высокая производительность**: Расчет Блэка-Шоулза < 100мс, биномиальная модель (100 шагов) < 500мс
- 📊 **Поддержка двух моделей**: Аналитическое решение Блэка-Шоулза + численный метод биномиального дерева
- 📈 **Полный набор греков**: Полное покрытие Delta, Gamma, Theta, Vega, Rho
- 🎨 **Визуализация**: Интерактивные графики цен опционов и кривых греков
- 🛡️ **Надежность**: Комплексная проверка входных данных, обработка исключений и журналирование ошибок
- 🌐 **Простота использования**: RESTful API + адаптивный веб-интерфейс

  - Обнаружение численной нестабильности

## Документация API

### Обзор конечных точек

### POST /api/price

Расчет цены опциона и греков.

**Тело запроса (JSON)**

```json
{
  "model": "black-scholes",
  "spot_price": 100.0,
  "strike_price": 105.0,
  "time_to_maturity": 1.0,
  "risk_free_rate": 0.05,
  "volatility": 0.2,
  "option_type": "call",
  "binomial_steps": 100,
  "calculate_greeks": true
}
```

**Описание параметров**

| Параметр | Тип | Обязательный | Описание | Диапазон |
|----------|-----|--------------|----------|----------|
| `model` | string | Да | Модель оценки | "black-scholes" или "binomial-tree" |
| `spot_price` | number | Да | Цена базового актива | > 0 |
| `strike_price` | number | Да | Цена исполнения | > 0 |
| `time_to_maturity` | number | Да | Время до истечения (годы) | > 0 |
| `risk_free_rate` | number | Да | Безрисковая ставка | Любое конечное значение |
| `volatility` | number | Да | Волатильность | ≥ 0 |
| `option_type` | string | Да | Тип опциона | "call" или "put" |
| `binomial_steps` | integer | Нет | Количество шагов | 10-1000 (только для биномиальной модели) |
| `calculate_greeks` | boolean | Нет | Рассчитывать ли греков | По умолчанию true |

**Успешный ответ (200 OK)**

```json
{
  "success": true,
  "model": "black-scholes",
  "option_price": 8.9162,
  "greeks": {
    "delta": 0.5596,
    "gamma": 0.0184,
    "theta": -6.4135,
    "vega": 36.7311,
    "rho": 51.8644
  },
  "computation_time_ms": 12
}
```

**Ответ с ошибкой (400 Bad Request)**

```json
{
  "success": false,
  "error": "Недопустимые входные параметры",
  "details": [
    "Цена базового актива должна быть положительной",
    "Волатильность должна быть неотрицательной"
  ]
}
```

### Пример теста

```cpp
// Тест паритета колл-пут
TEST_F(BlackScholesEngineTest, PutCallParity) {
    OptionParams call_params;
    call_params.spot_price = 100.0;
    call_params.strike_price = 105.0;
    call_params.time_to_maturity = 1.0;
    call_params.risk_free_rate = 0.05;
    call_params.volatility = 0.2;
    call_params.option_type = OptionType::Call;
    
    OptionParams put_params = call_params;
    put_params.option_type = OptionType::Put;
    
    PricingResult call_result = engine.calculate(call_params);
    PricingResult put_result = engine.calculate(put_params);
    
    // Проверка C - P = S - K*e^(-rT)
    double left_side = call_result.option_price - put_result.option_price;
    double right_side = call_params.spot_price - 
                       call_params.strike_price * 
                       std::exp(-call_params.risk_free_rate * 
                               call_params.time_to_maturity);
    
    EXPECT_NEAR(left_side, right_side, 0.01);
}
```

## Обработка ошибок

### Проверка входных данных

Система выполняет проверку входных данных сразу после получения запроса:

- ✅ Все ценовые параметры > 0
- ✅ Волатильность ≥ 0
- ✅ Время до истечения > 0
- ✅ Безрисковая ставка - конечное значение
- ✅ Количество шагов биномиального дерева в диапазоне [10, 1000]
- ✅ Тип опциона "call" или "put"

При неудачной проверке возвращается HTTP 400 с подробным списком ошибок.

### Обработка исключений

Движок оценки перехватывает и обрабатывает:

- Числовое переполнение/потеря значимости
- Ошибки деления на ноль
- Недопустимые математические операции (например, квадратный корень из отрицательного числа)
- Неконечные значения (NaN, Infinity)

### Предупреждения об экстремальных значениях

Система обнаруживает следующие экстремальные ситуации и выдает предупреждения:

- Волатильность > 200%
- Время до истечения > 10 лет
- Соотношение цен (S/K) > 10 или < 0.1
- Процентная ставка > 50% или < -10%

Предупреждения не блокируют расчет, но включаются в ответ.

### Журналирование ошибок

Все ошибки и предупреждения записываются в стандартный поток ошибок:

```
[2024-12-08 10:30:45.123] [ERROR] [BlackScholesEngine] Недопустимый ввод: Цена базового актива должна быть положительной (значение: -100.0)
```
