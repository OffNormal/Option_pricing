# Chart.js 可视化测试指南

## 快速测试

### 选项 1: 独立测试页面（推荐）
最简单的测试方法，无需后端服务器：

1. 直接在浏览器中打开文件:
   ```
   web/test_visualization.html
   ```

2. 你应该看到:
   - 两个完整的图表
   - 价格曲线图（紫蓝色曲线）
   - 希腊值曲线图（5条不同颜色的曲线）

3. 测试交互功能:
   - 悬停在数据点上查看工具提示
   - 检查图例是否正确显示
   - 验证坐标轴标签是否清晰

### 选项 2: 主应用测试
需要后端服务器运行（任务 17 完成后）：

1. 启动后端服务器
2. 在浏览器中打开 `http://localhost:8080`
3. 填写期权参数:
   - 标的资产价格: 100
   - 执行价格: 105
   - 到期时间: 1.0
   - 无风险利率: 0.05
   - 波动率: 0.20
4. 点击"计算期权价格"
5. 滚动查看可视化图表

## 常见问题

### Q: 图表不显示
A: 检查以下几点:
1. 确保 Chart.js CDN 链接可访问
2. 检查浏览器控制台是否有错误
3. 确认数据格式正确

### Q: 图表显示但样式不对
A: 
1. 清除浏览器缓存
2. 检查 CSS 文件是否正确加载
3. 验证 Chart.js 版本是否为 4.4.0

### Q: 工具提示不显示
A:
1. 确保悬停在数据点附近
2. 检查 tooltip 配置是否正确
3. 验证数据数组长度匹配

## 数据格式示例

如果你想测试自定义数据，使用以下格式:

```javascript
const visualizationData = {
  price_curve: {
    x: [80, 85, 90, 95, 100, 105, 110, 115, 120],
    y: [2.5, 4.2, 6.8, 10.1, 14.2, 18.9, 24.1, 29.5, 35.2]
  },
  greeks_curves: {
    delta: {
      x: [80, 85, 90, 95, 100, 105, 110, 115, 120],
      y: [0.25, 0.35, 0.48, 0.62, 0.75, 0.85, 0.91, 0.95, 0.97]
    },
    gamma: {
      x: [80, 85, 90, 95, 100, 105, 110, 115, 120],
      y: [0.015, 0.020, 0.024, 0.025, 0.023, 0.019, 0.014, 0.010, 0.007]
    },
    // ... 其他希腊值
  }
};

// 调用显示函数
displayVisualization(visualizationData);
```

## 性能提示

- 建议数据点数量: 30-100 个
- 过多数据点可能影响渲染性能
- 使用 `tension: 0.4` 获得平滑曲线
- 图表实例会在更新时自动销毁旧实例
