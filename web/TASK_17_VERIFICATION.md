# Task 17 验证文档：前后端通信实现

## 实现概述

本任务实现了OptionPricer系统的前后端通信功能，包括：

1. **Fetch API集成** - 使用现代Fetch API发送HTTP请求
2. **JSON数据处理** - 正确序列化请求和反序列化响应
3. **加载状态指示器** - 提供用户友好的加载反馈
4. **错误处理** - 处理网络错误、超时和服务器错误
5. **超时控制** - 实现请求超时机制

## 实现的功能

### 1. API通信函数

#### `callPriceAPI(formData)`
- 发送POST请求到 `/api/price`
- 包含所有期权参数
- 5秒超时限制
- 返回计算结果或错误信息

#### `callVisualizationAPI(formData)`
- 发送POST请求到 `/api/visualize`
- 生成可视化数据
- 10秒超时限制（可视化计算更耗时）
- 返回图表数据或错误信息

### 2. 错误处理

实现了三种错误类型的处理：

1. **网络错误** - 无法连接到服务器
2. **超时错误** - 请求超过时间限制
3. **服务器错误** - 服务器返回错误响应（400, 500等）

### 3. 加载状态管理

- 禁用表单输入和按钮
- 显示加载动画
- 防止重复提交

### 4. 用户体验改进

- 清晰的错误消息
- 平滑的状态转换
- 详细的错误详情显示

## 技术实现细节

### 请求格式
```javascript
{
  model: "black-scholes" | "binomial-tree",
  option_type: "call" | "put",
  spot_price: number,
  strike_price: number,
  time_to_maturity: number,
  risk_free_rate: number,
  volatility: number,
  binomial_steps?: number  // 仅二叉树模型
}
```

### 响应格式
```javascript
{
  success: boolean,
  model: string,
  option_price: number,
  greeks: {
    delta: number,
    gamma: number,
    theta: number,
    vega: number,
    rho: number
  },
  computation_time_ms: number
}
```

### 错误响应格式
```javascript
{
  success: false,
  error: string,
  details: string[]
}
```
