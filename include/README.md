# Header Files

This directory will contain C++ header files for the OptionPricer platform.

## Planned Headers

- `option_types.h` - Core data structures (OptionParams, PricingResult, Greeks)
- `pricing_engine.h` - IPricingEngine interface
- `black_scholes_engine.h` - Black-Scholes implementation
- `binomial_tree_engine.h` - Binomial tree implementation
- `input_validator.h` - Input validation
- `server.h` - HTTP server
- `visualization_generator.h` - Visualization data generation

These files will be implemented in subsequent tasks.
