# Test Suite

This directory will contain unit tests and property-based tests for the OptionPricer platform.

## Test Framework

- Google Test for unit tests
- RapidCheck for property-based tests

## Planned Test Files

- `test_black_scholes.cpp` - Black-Scholes engine tests
- `test_binomial_tree.cpp` - Binomial tree engine tests
- `test_properties_pricing.cpp` - Property-based tests for pricing
- `test_properties_greeks.cpp` - Property-based tests for Greeks
- `test_input_validator.cpp` - Input validation tests

These files will be implemented in subsequent tasks.
